# UnlimitedClipper 0.1.0-preview.11

Studio tools now use compact icon tabs above the player. The layout gives the preview more
room, reduces oversized headings, and stacks four tool columns on a phone. The right inspector
opens when a tool is selected, even after it was hidden.

The Audio panel can search and audition imported sounds, place one at the playhead, and filter
built-in effects by name or category. Each audio layer can use fades, optional loudness
normalization, or ducking against the source soundtrack. Exact preview and export render these
settings; live playback is an approximation. The soundboard link opens an external catalog;
its sounds are not bundled or fetched automatically.

The Hook editor can move an existing 0.3-to-5-second moment to the beginning. The source moment
is removed from its old position, keeping total duration unchanged. The operation remaps
captions, layer timing, media offsets, and motion, then enters Undo/Redo and normal autosave.

Project clip cards now have one Edit clip action. The Studio timeline shows a waveform measured
from source audio, and imported audio layers show waveforms from their selected source ranges.
Audio, B-roll, and filter assets can be dragged onto their tracks. The project B-roll library
accepts local videos and CC0 Wikimedia Commons footage with visible provenance and a preview.
Filters can occupy timed blocks, and scene boundaries can use Cut or Dip to black.

Camera, text, and B-roll motion controls use a selectable keyframe strip. Export history shows
playable videos directly. Buttons, headings, and the preview layout use tighter spacing; the
README screenshots come from a native Windows ARM64 development window. These desktop captures
are separate from installer execution and other-platform runtime checks.

The tagged workflow records Windows FFmpeg build flags and verifies pinned source coverage
and platform notices before creating and publishing a release. The application updater still
lists Windows installers only. Linux and macOS installation, system signing, and Android device
runtime require separate validation.
This release must remain unpublished until the source and notice audit passes for every bundled
media build.
