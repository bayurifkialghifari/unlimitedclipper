# UnlimitedClipper 0.1.0-preview.2

An experimental Windows desktop preview for trying local video clipping. This is a side project,
and captions and automatic moment selection still need human review.

## Download

- Windows on Snapdragon/ARM: choose the installer ending in **arm64-setup.exe**.
- Windows on Intel/AMD: choose the installer ending in **x64-setup.exe**.
- **SHA256SUMS** contains hashes for the attached installers and updater files.

Install for the current Windows user. The installer includes the studio and native media tools.
WebView2 may download during installation if it is missing. On first use, install the local AI
models in Settings: Whisper small is about 190 MB and Qwen3 is about 2.50 GB. Whisper medium and
the experimental 1.61 GiB speech pack are optional. Models are stored separately from the installed
application. No API keys are needed.

## Included

- Local files and YouTube imports through yt-dlp.
- Local transcription and reviewable moment/editing suggestions.
- Five caption looks, including Kinetic, with editable words, timing, emphasis, and position.
- Multiple source segments, notes, punch-ins, split framing, local B-roll, and audio layers.
- Composed previews, revision-aware autosave, undo/redo, MP4/subtitle exports, and job recovery.
- A compact progress popup for uploads, model downloads, clipping stages, and exports, with
  completion/failure alerts and cancellation that waits for processing to stop.
- An AI-model dropdown with in-app downloads and an optional manual file import.
- Simple update controls without asking users to enter server addresses.

## Verification limits

The current source passed frontend checks, 26 Rust tests, and native Windows ARM64 media rendering.
Browser and earlier debug desktop interactions were tested separately. The optimized ARM64 preview
host also passed native model selection, a real clipping-progress popup, and queued-test-job
cancellation while preserving the user's transcription. This preview provides newly built
installers; their install/uninstall and physical x64 runtime behavior have not been certified.
Native speech-pack accuracy and podcast benchmarks remain pending.

Updater artifacts are signed with a publisher key. Windows Authenticode signing is not configured,
so Windows may show an unknown-publisher prompt. The repository is private: downloading requires
GitHub access, and these URLs are not a public automatic-update feed. Linux/macOS packages and a
new Android package are outside this Windows preview. The earlier Android APK remains untested on
a device.

Both installers were built locally from tagged application source
961e30143bc6e8f0c013138f424fb2511042e075 because hosted CI could not start due to account billing.
Staging uses the signer-environment fix in b3e0d84. Version-bound publisher signatures and every
published asset's SHA-256 were verified. Some installer prompts remain in English when Indonesian
is selected.

Keep a backup of your project library when trying preview builds.
