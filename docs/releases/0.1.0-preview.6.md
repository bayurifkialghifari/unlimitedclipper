# UnlimitedClipper 0.1.0-preview.6

The Studio inspector now has one themed scrollbar. Economy discovery uses installed Qwen3
1.7B for proposals and installed 4B for independent review, with Podcast/Gaming profiles,
bounded extra search, and an explicit accepted/target report. One installed Qwen model can
handle both stages. Models load sequentially with a 4,096-token context.

## Fixes and additions

- Censored speech no longer drops later transcript words. Matching cached Whisper recognition
  restores old source words without another speech-model run; existing clip edits are preserved.
- Models select numbered phrases; Rust supplies exact source boundaries and quotes. Full
  candidate review rejects weak or invalid results instead of padding the requested count.
- Scene-aware Follow, stable two-face split layers, and constrained gaming Facecam use bounded
  frame streaming and revision-safe recovery. Active speaker detection is not included.
- Dense motion renders through balanced crop expressions and managed FFmpeg graph files,
  fixing expression-depth and Windows command-line failures in preview and export.
- Optional medium recognition refines uncertain generated cuts with retry-safe child jobs.

## Validation and limits

On the tested Windows ARM64 PC, a 48.47-minute real podcast restored 8,894 source words
(previously 2,410) and produced four qualifying clips of a four-clip target. Selection
took about 9.93 minutes using cached recognition. One 53.52-second natural cut completed
caption refinement, tracking, and full-decoded 720p export. A controlled moving two-face
fixture passed split framing across reordered scenes, and a separate 300-anchor fixture
passed both edited preview and export.

Frontend checks, 43 Rust tests, Rustfmt, engine/desktop Clippy, and 11 browser scenarios
passed locally. These results do not certify AI accuracy, predicted virality, all-frame
tracking, or hosted-service parity. Review clips and captions before publishing.

Windows ARM64 and x64 installers are built by the tagged release workflow. Publisher
updater signatures are separate from Windows Authenticode, which is not configured.
Physical x64, macOS, Linux, Android, installer execution, and automatic updater execution
remain unverified. Android runtime has not been tested.

Start with Whisper small, Economy, and 720p on a constrained PC. The tested machine has
16 GB RAM. An 8 GB small-model-only setup or 12–16 GB paired-model setup is a planning
estimate rather than a certified minimum. See [validation](../validation.md) and
[processing strategy](../research/economy-processing.md) for measured scope.
