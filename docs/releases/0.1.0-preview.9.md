# UnlimitedClipper 0.1.0-preview.9

This preview makes styling an existing clip easier. Choose Change style on a saved clip or
export record to open that clip's caption controls. Caption and video styles save per clip;
export again to create a new MP4. Earlier exports keep their original revision and files.

The Hook tab now presents local ideas as a numbered list with the selected idea's source
quote and explanation. A presentation edit does not require generating the same ideas again.
Source-range, scene, or transcript changes invalidate them. Manual overlay and opening-card
controls can switch formats without local inference.

The tagged workflow builds Windows x64/ARM64 installers, Linux x64/ARM64 AppImages, macOS
Intel/ARM disk images, and an experimental Android ARM64 debug APK when all CI jobs pass.
It stages a draft release for package and notice inspection before publication.
Unix packages carry license texts, FFmpeg build configuration, and native tool provenance.
macOS package staging checks the executable inside each produced disk image.
The release also attaches notice archives and pinned media source/build-script snapshots;
see THIRD-PARTY-NOTICES.md for component scope and source directions.
The Android native media AAR, build evidence, and license accompany the experimental APK.
Only Windows packages participate in the application update manifest. Linux/macOS desktop
runtime, installers, system signing/notarization, and Android device behavior remain unverified
until the release evidence records those checks. The Android APK currently supports media-only
manual clipping; local AI and YouTube import are disabled. Keep its original export files before
uninstalling a debug APK, because debug signing may change between builds.

AI hook ideas and clip selection remain suggestions that need editorial review.
