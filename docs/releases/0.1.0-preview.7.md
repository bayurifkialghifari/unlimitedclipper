# UnlimitedClipper 0.1.0-preview.7

This experimental Windows preview adds an editable opening hook, footage color controls,
offline whoosh/click/tap sounds, and clearer manual clipping. It also hardens caption canvas
cleanup and edited-preview loading. It is still a hobby project with incomplete certification.

- Hook text, font, color, start time, duration, and animation remain editable and export with
  the selected revision. Three original looks are included.
- Five color recipes and four adjustments share rendered preview/export composition.
- 21 CC0 sounds work offline, with audition, placement, trimming, and gain controls.
- Manual clip boundaries use original-source seconds. Motivation, Education, and Other content
  keep the same local models, context limits, and grounded review as existing profiles.

On the developer's Windows ARM64 laptop, a real 16.26-second podcast demo exported at
1080 x 1920 in roughly 34 seconds and played with video, captions, hook, and audio. This reused
existing caption edits and does not include transcription/discovery. Native manual edits and
original edit preservation passed. See ../validation.md for evidence and limitations.

Windows ARM64 is for Snapdragon/ARM PCs; Windows x64 is for Intel/AMD PCs. Installer execution,
automatic update installation, physical x64, other desktop OS runtime, and Android runtime
remain unverified. Color changes require Render Edited preview; Source remains quick review.
AI suggestions and editorial scores require manual review and do not predict views.
