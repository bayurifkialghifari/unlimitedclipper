# UnlimitedClipper 0.1.0-preview.5

An experimental local clipping app. This preview adds 18 editable caption looks, named reusable
styles, and local clip potential reviews with quoted transcript evidence. The studio and original
icon use graphite/amber, the sidebar is simpler, and Processing retains aligned progress rows
with compact retry controls. Cross-drive WebView2 resource staging is fixed for hosted builds.

Choose the ARM64 installer for Windows on ARM or the x64 installer for Intel/AMD Windows. Both
bundle the media tools and fonts. AI models download separately in Settings.

SHA256SUMS and architecture-specific updater signatures accompany the installers. These are
publisher updater signatures; Windows Authenticode signing is not configured.

Local checks cover frontend quality, 35 engine tests, Rustfmt/Clippy, real caption rendering,
browser editing, and actual Qwen inference. Ratings describe transcript-based editorial potential
and do not predict views. AI recognition and suggestions still need human review.

Physical x64 runtime, full installer/updater execution, macOS/Linux packaging, and Android runtime
remain unverified. Android's existing media-only preview is unchanged. This release supplies
Windows installers; other operating systems are covered by source CI rather than certified packages.

The [tagged workflow](https://github.com/bayurifkialghifari/unlimitedclipper/actions/runs/43610553764)
published eight verified assets. Both installers downloaded anonymously and passed independent
publisher-signature, signed-version, and SHA-256 verification. The ARM64 application extracted
from that installer opened on Windows ARM64 with the real library. This does not certify
install/uninstall or updater execution.
