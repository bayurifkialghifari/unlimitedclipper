# UnlimitedClipper 0.1.0-preview.3

A Windows desktop preview with a local transcript and scene timeline editor. This is an
experimental side project; automatic moment selection and caption recognition need human review.

## Download and setup

- Snapdragon/ARM Windows PCs: choose **arm64-setup.exe**.
- Intel/AMD Windows PCs: choose **x64-setup.exe**.
- **SHA256SUMS** contains the attached installers and updater-file checksums.

Install for the current Windows user. Media tools and the studio are included. WebView2 may
download if missing. In Settings, choose and download Whisper small (about 190 MB) and Qwen3
(about 2.50 GB) for local AI. Models stay separate from application binaries. Manual model import
remains available. Whisper medium and the experimental speech pack are optional.

## Changed

- Select transcript words to seek, edit text, remove captions, or cut a range from the video.
- Reorder, split, delete, and trim scenes on a zoomable timeline with snapping and keyboard
  controls. Source timing, caption corrections, crop anchors, and media offsets survive edits.
- Move/trim visual and audio layers. A drag saves one transaction and supports undo.
- Review source scenes in output order, or render an edited preview through the export pipeline.
  Stale composed media pauses until refreshed.
- Use the full window on project, export, processing, and settings pages. Export cards play
  actual saved media with immutable subtitles; Settings actions have labeled icons.
- Completed activity notices clear after six seconds; active processing and errors stay visible.
- The app, taskbar, installer, browser, and README share the original frame/cut icon.

## Verification limits

Frontend checks, 32 Rust tests, Rustfmt, and engine/desktop Clippy passed. All eight browser
tests passed together. Real generated media verified reordered video colors, audio frequencies,
subtitle order, timing, full decoding, and immutable revisions in all six export layouts.
The optimized ARM64 host separately passed native file import, scene reorder, caption autosave,
composed playback, and export playback in an isolated library.

Both installers were built locally from the application source represented by this tag. Their
Windows version metadata, native ARM64/x64 PE headers, version-bound publisher signatures, and
all staged SHA-256 checksums passed independent verification. Hosted
[quality checks](https://github.com/bayurifkialghifari/unlimitedclipper/actions/runs/43599820651) and
[media checks](https://github.com/bayurifkialghifari/unlimitedclipper/actions/runs/43599820615)
could not start because GitHub reported an account billing/spending-limit restriction.

Installer install/uninstall, updater installation, and physical x64 runtime remain untested.
The editor does not offer real-time GPU compositing or verified OpusClip-equivalent AI accuracy.
Android runtime remains untested; Linux/macOS packaging is outside this Windows preview.

Publisher updater signatures bind the release version. Windows Authenticode signing is not
configured, so Windows may show an unknown-publisher prompt. The repository is private: downloads
require GitHub access, and these links are not a public automatic-update feed. Some installer
messages fall back to English when Indonesian is selected. Keep a backup of your project library
when trying preview builds.
