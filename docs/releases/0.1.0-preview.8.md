# UnlimitedClipper 0.1.0-preview.8

This experimental preview adds image thumbnails to the five video filters. Compare each
look on the same source frame, refresh from the source player, and see a larger still image
respond to brightness, contrast, saturation, and warmth controls. Captures stay in memory
at a maximum 320-pixel edge and do not start another decoder or render job.

Thumbnail colors are quick RGB approximations. Render Edited remains the exact review of
video composition, titles, captions, SFX, and color adjustments before export. This preview
also retains the timed hook editor, 21 offline sounds, and explicit manual source ranges.

Exports remain in the application's managed data directory. Choosing an export folder in
Settings is planned for later. Windows ARM64 is for Snapdragon PCs; x64 is for Intel/AMD.
Physical x64, installer/updater execution, other desktop OS runtime, and Android runtime
remain unverified. This is a hobby project; AI suggestions require review.
