# Research record

Research date: 2026-11-13. Public pages and upstream release metadata were inspected directly. Product behavior beyond public demonstrations is not claimed to have been tested.

| Source                                                                              | Finding                                                                                                                                                | Implementation consequence                                                          |
| ----------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------- |
| [editorial reference](editorial reference)                                         | Public feature groups cover captions, titles, crop/keyframes, gaming split, watermarks, galleries, languages, and orientations.                        | Match the editing workflow and capability coverage with original source and assets. |
| [SupoClip](https://github.com/FujiwaraChoki/supoclip)                               | AGPL project with cloud provider defaults, optional local models, and download/checkpoint recovery.                                                    | Reference workflows; do not incorporate source into the original product.           |
| [yt-dlp](https://github.com/yt-dlp/yt-dlp)                                          | Native Windows ARM64/x64 releases; EJS plus a JavaScript runtime supports YouTube challenges. Bundled executable licenses differ from source licenses. | Bundle the complete toolchain and retain its third-party notices.                   |
| [Deno releases](https://github.com/denoland/deno/releases)                          | Windows ARM64 and x64 artifacts exist.                                                                                                                 | No separately installed JavaScript runtime is required by the application.          |
| [FFmpeg builds](https://github.com/FFmpeg-Builds/FFmpeg-Builds/releases)            | Windows ARM64 and x64 packages exist.                                                                                                                  | Pin a complete FFmpeg build and corresponding source/license record.                |
| [Whisper.cpp](https://github.com/ggml-org/whisper.cpp)                              | CPU inference, quantized multilingual models, experimental word timing, and ARM64 binaries.                                                            | Benchmark local transcription and validate timed caption behavior.                  |
| [Qwen3 4B GGUF](https://huggingface.co/Qwen/Qwen3-4B-GGUF)                          | Official Apache-2.0 Q4_K_M model, approximately 2.50 GB; supports disabling thinking.                                                                  | Use bounded structured local selection.                                             |
| [Whisper models](https://huggingface.co/ggerganov/whisper.cpp)                      | Small Q5_1 is 190,085,487 bytes; medium Q5_0 is 539,212,467 bytes.                                                                                     | Small default, medium optional; show accurate download estimates.                   |
| [YuNet](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet) | Small MIT-licensed face detector.                                                                                                                      | Use detected faces to produce editable crop tracks.                                 |
| [ONNX Runtime](https://github.com/microsoft/onnxruntime/releases)                   | Native Windows ARM64 and x64 distributions exist.                                                                                                      | Keep detection local.                                                               |
| [JASSUB](https://github.com/ThaUnknown/jassub)                                      | Browser libass renderer with local font support and single-thread fallback.                                                                            | Share generated ASS and font assets with export.                                    |
| [Tauri updater](https://v2.tauri.app/plugin/updater/)                               | Mandatory artifact signatures and architecture-specific update feeds.                                                                                  | Stage and verify updates; do not replace active tools.                              |
| [SQLite WAL](https://sqlite.org/wal.html)                                           | Same-host storage, concurrent readers, and one writer.                                                                                                 | Keep the database local and writes short.                                           |
| [Anti-slop](https://github.com/miqdadbadjuber/anti-slop)                            | Requires explicit direction, real behavior, resilience, and evidence.                                                                                  | During mode; record interaction and delivery gates.                                 |

The current development PC is Windows 11 ARM64, Snapdragon X with eight CPU cores and approximately 16 GB RAM. Node.js currently runs as x64 through Windows emulation. Rust targets ARM64 natively. Visual Studio C++ tools are absent, so a workspace-local compiler route is needed before native builds.
