# Platform support

| Platform         | Implementation                                                          | Validation                                                                                                                                                                                                     |
| ---------------- | ----------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Windows 11 ARM64 | Native Rust engine, local media tools, React studio, Tauri NSIS package | Engine, browser workflows, speech/selection/title inference, tracking, six export compositions, and installer build tested on Snapdragon X. Installation and native interaction checks are tracked separately. |
| Windows 11 x64   | Matching native toolchain and configurable Rust target                  | Toolchain downloaded. Native engine and desktop certification remain separate from ARM64 results.                                                                                                              |
| macOS            | Shared engine/UI architecture                                           | Packaging, media distributions, signing, and runtime certification pending.                                                                                                                                    |
| Linux            | Shared engine/UI architecture                                           | Packaging, media distributions, and runtime certification pending.                                                                                                                                             |
| Android          | Future native-library integration                                       | Desktop subprocess assumptions cannot be reused directly. Implementation follows desktop clipping stability.                                                                                                   |
| Local browser    | Same loopback API and SQLite state as desktop                           | Chromium import/edit/reopen/export/download and responsive interface tested.                                                                                                                                   |

ARM64 and x64 are separate artifacts. Emulation tests do not establish performance or compatibility on a physical x64 computer. Public internet hosting is outside this local-first release.
