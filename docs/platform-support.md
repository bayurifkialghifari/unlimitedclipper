# Platform support

| Platform         | Implementation                                                             | Validation                                                                                                                                                                                                                                   |
| ---------------- | -------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Windows 11 ARM64 | Native Rust engine, local media tools, React studio, Tauri NSIS package    | Tested on Snapdragon X: engine/browser, local inference, tracking, six compositions, native workflows, and the real library. The preview.2 optimized host and signed package inspection passed; preview.2 install/uninstall remains pending. |
| Windows 11 x64   | Native Rust engine, local media tools, React studio, Tauri NSIS package    | Earlier MSVC engine tests and desktop Clippy passed in Windows CI. The preview.2 optimized build, NSIS packaging, signatures, and checksums passed locally. Physical x64 inference/export and install/uninstall remain pending.              |
| macOS Intel      | Shared engine/UI architecture                                              | Engine tests and Clippy passed on macos-15-intel. Desktop packaging, media distributions, signing, and runtime certification remain pending.                                                                                                 |
| macOS ARM64      | Shared engine/UI architecture                                              | Engine tests and Clippy passed on macos-15 Apple Silicon. Desktop packaging, media distributions, signing, and runtime certification remain pending.                                                                                         |
| Linux            | Shared engine/UI architecture                                              | Engine tests and Clippy passed on Ubuntu 24.04. Debian/Arch packaging, media distributions, and runtime certification remain pending.                                                                                                        |
| Android          | Media-only Tauri APK with a private Rust engine and native FFmpeg/FFprobe. | ARM64 APK build, SDK metadata, signature, and 16 KB native/ZIP alignment passed. Intended device: Snapdragon 8+ Gen 1, 12 GB RAM. Runtime intentionally untested. See [Android requirements](android.md).                                    |
| Local browser    | Same loopback API and SQLite state as desktop                              | Chromium import/edit/reopen/export/download and responsive interface tested.                                                                                                                                                                 |

ARM64 and x64 are separate artifacts. Emulation tests do not establish performance or compatibility on a physical x64 computer. Public internet hosting is outside this local-first release.

The [Windows preview](https://github.com/bayurifkialghifari/unlimitedclipper/releases/tag/v0.1.0-preview.2)
is available for both architectures. See [validation evidence](validation.md) for source revisions,
published artifact checks, hosted CI restrictions, and runtime limits.
