# Platform support

| Platform         | Implementation                                                          | Validation                                                                                                                                                                                           |
| ---------------- | ----------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Windows 11 ARM64 | Native Rust engine, local media tools, React studio, Tauri NSIS package | Tested on Snapdragon X: engine, browser workflows, local inference, tracking, six compositions, final installer, native import/edit/export, single instance, reopening, and the real Windah library. |
| Windows 11 x64   | Matching native toolchain and configurable Rust target                  | MSVC engine tests and desktop Clippy passed in Windows CI. Toolchain downloaded. Physical x64 inference/export and installer certification remain pending.                                           |
| macOS Intel      | Shared engine/UI architecture                                           | Engine tests and Clippy passed on macos-15-intel. Desktop packaging, media distributions, signing, and runtime certification remain pending.                                                         |
| macOS ARM64      | Shared engine/UI architecture                                           | Engine tests and Clippy passed on macos-15 Apple Silicon. Desktop packaging, media distributions, signing, and runtime certification remain pending.                                                 |
| Linux            | Shared engine/UI architecture                                           | Engine tests and Clippy passed on Ubuntu 24.04. Debian/Arch packaging, media distributions, and runtime certification remain pending.                                                                |
| Android          | Future native-library integration                                       | Desktop subprocess assumptions cannot be reused directly. Implementation follows desktop clipping stability.                                                                                         |
| Local browser    | Same loopback API and SQLite state as desktop                           | Chromium import/edit/reopen/export/download and responsive interface tested.                                                                                                                         |

ARM64 and x64 are separate artifacts. Emulation tests do not establish performance or compatibility on a physical x64 computer. Public internet hosting is outside this local-first release.
